ปัญหาในการบริหารเอกสารโครงการก่อสร้าง

คลิกที่หัวข้อเพื่อดูว่า EDMIS แก้ปัญหานี้อย่างไร

01

เอกสารส่งกันหลงทาง ไม่ทราบว่าใครรับผิดชอบ

▾
ระบบกำหนดกระบวนการส่ง-รับเอกสารผ่าน Inbox/Sent ของแต่ละหน่วยงาน พร้อมระบุผู้รับและสถานะเอกสารอย่างชัดเจน
02

ไม่ทราบสถานะเอกสารว่าอยู่ขั้นตอนใด

▾
ติดตามสถานะเอกสาร (Document Status) เช่น ฉบับร่าง รออนุมัติ อนุมัติแล้ว ตีกลับ ได้แบบเรียลไทม์
03

การอนุมัติช้า ไม่ทราบว่ารออยู่ที่ใคร

▾
แจ้งเตือนผ่าน LINE และ Email ทันทีเมื่อมีเอกสารวนมาถึงผู้ที่เกี่ยวข้อง เร่งรอบการอนุมัติให้เร็วขึ้น
04

เอกสารสำคัญสูญหาย หรือค้นหายาก

▾
จัดเก็บเอกสารแบบรวมศูนย์ พร้อม Global Search และระบบกู้คืนไฟล์ (Recovery Files)
05

ตรวจสอบย้อนกลับไม่ได้ว่าใครแก้ไขข้อมูล

▾
บันทึกการเปลี่ยนแปลงทุกครั้งใน Audit Log ตรวจสอบได้ว่าใครทำอะไร เมื่อใด
06

การทำ Close-out โครงการกระจัดกระจาย

▾
โมดูล Close-out รวบรวมเอกสาร การตรวจสอบ และ Punch List ไว้ในที่เดียว จบงานได้ครบในระบบเดียว
ฟีเจอร์ระบบ

โมดูลการทำงานครบวงจร

เลือกดูฟีเจอร์ตามหมวดหมู่การทำงาน

RFA (Request For Approval)

เอกสารขออนุมัติ พร้อมเลขเอกสารอัตโนมัติ สถานะ ความคิดเห็น และพิมพ์ Cover Sheet มาตรฐาน

RFI (Request For Information)

เอกสารขอข้อมูลเพิ่มเติมระหว่างฝ่ายต่าง ๆ พร้อม Cover Sheet

Shop Drawing

จัดการแบบก่อสร้างที่ต้องส่งเข้าพิจารณา

As-Build Plan

จัดการแบบก่อสร้างตามที่ก่อสร้างจริง

Submittals

จัดการเอกสารที่ต้องส่งให้ผู้ว่าจ้างพิจารณา

Letter Internal

จัดการหนังสือภายในองค์กร แยกตามหน่วยงาน พร้อมระบบส่ง-รับและติดตามสถานะ

Letter External

จัดการหนังสือภายนอกองค์กร ส่ง-รับระหว่างหน่วยงานภายนอกและผู้รับเหมา

NCR

รายงานการไม่เป็นไปตามข้อกำหนด (Non-Conformance Report)

NCN

หนังสือแจ้งการไม่เป็นไปตามข้อกำหนด (Non-Conformance Notice)

SWN

หนังสือแจ้งการทำงานภาคสนาม (Site Work Notice)

Check List / Check Sheet

รายการตรวจสอบและใบตรวจสอบงาน

Inspection

การตรวจสอบและรับงานก่อสร้าง

Close Out Main

หน้าหลักของการปิดงานโครงการ

Close Out Description

รายละเอียดของการปิดงาน

Close Out Inspection

การตรวจสอบก่อนปิดงาน

Punch List

รายการงานที่ต้องแก้ไขก่อนปิดงาน

Location / Work Type

จัดการตำแหน่งและประเภทงาน

Close Out Drive

จัดการไฟล์และไดรฟ์เอกสารปิดงาน

Construction Contract

จัดการสัญญาก่อสร้างของโครงการ

BoQ

รายการปริมาณงาน (Bill of Quantities)

Variation Order

ใบสั่งเปลี่ยนแปลงงาน

Interim Payment

การจ่ายเงินงวดงาน

Provisional Sum

เงินสำรองชั่วคราว

Daily / Monthly Report

รายงานประจำวันและประจำเดือนของ Constructor / CSC

Meeting Weekly/Monthly

จัดการการประชุมประจำสัปดาห์และเดือน

Activity / Task Calendar

ปฏิทินกิจกรรมและงานของโครงการ

WBS Level 1–5

โครงสร้างการแบ่งงาน 5 ระดับ

File Manager / Global Search

จัดการไฟล์และค้นหาข้อมูลทั้งระบบ

Messenger / Announcement

ส่งข้อความภายในและประกาศองค์กร

แจ้งเตือนอัตโนมัติ

ไม่พลาดทุกความเคลื่อนไหวของเอกสาร

แจ้งเตือนแบบเรียลไทม์ผ่าน LINE, Email และ In-App ให้ผู้เกี่ยวข้องตอบสนองได้ทันที

แจ้งเตือนผ่าน LINE

  • มีเอกสาร RFA/RFI ใหม่ส่งเข้ามา
  • เอกสารเปลี่ยนสถานะ (อนุมัติ / ตีกลับ / ปิดงาน)
  • มีงาน (Task) ใหม่มอบหมายให้ผู้ใช้
  • ใกล้ถึงกำหนดเวลาส่งมอบเอกสาร
  • กำหนดกลุ่มผู้รับตามบทบาทหรือทีมได้

แจ้งเตือนผ่าน Email

  • มีเอกสารใหม่ถูกสร้างในระบบ
  • เอกสารถูกแก้ไขหรือเปลี่ยนสถานะ
  • มีการมอบหมายงานใหม่ให้ผู้ใช้
  • ประกาศหรือแจ้งเตือนสำคัญจากระบบ
  • แนบลิงก์เข้าสู่ระบบเพื่อดูรายละเอียดทันที

แจ้งเตือนในแอป (In-App)

  • ป๊อปอัปแจ้งเตือนเมื่อเข้าสู่ระบบ
  • แสดงไอคอนจำนวนการแจ้งเตือนที่ยังไม่อ่าน
  • ดูประวัติการแจ้งเตือนทั้งหมดในหน้า Notification
  • กดเพื่อไปยังเอกสารหรืองานที่เกี่ยวข้องได้ทันที
  • ตั้งค่าการแจ้งเตือนตามความต้องการของผู้ใช้

จุดเด่น

ทำไมต้อง EDMIS

ออกแบบมาเพื่อโครงการก่อสร้างขนาดกลางถึงขนาดใหญ่โดยเฉพาะ

01

รองรับหลายสัญญาและหลายโครงการ

จัดการเอกสารแยกตามสัญญาก่อสร้างได้ในระบบเดียว

02

สิทธิ์การเข้าถึงละเอียด

ควบคุมได้ระดับผู้ใช้ ระดับทีม และระดับโมดูล

03

Audit Log ครบถ้วน

บันทึกการเปลี่ยนแปลงทุกครั้ง ตรวจสอบย้อนกลับได้

04

เลขเอกสารอัตโนมัติ

ลดข้อผิดพลาดจากการตั้งเลขเอกสารเอง

05

Cover Sheet มาตรฐาน

พิมพ์เอกสาร RFA/RFI รูปแบบมาตรฐานได้ทันที

06

รองรับไฟล์หลายประเภท

อัปโหลด PDF รูปภาพ ไฟล์ CAD และวิดีโอขนาดใหญ่ได้

07

Global Search

ค้นหาข้อมูลทั้งระบบได้จากจุดเดียว

08

ระบบกู้คืนไฟล์

ลดความเสี่ยงจากการลบไฟล์โดยไม่ตั้งใจ

09

นำเข้าข้อมูลจาก CSV

ย้ายข้อมูลจากระบบเดิมได้สะดวก รวดเร็ว

บริการเสริม

Custom เพิ่มเติมตามความต้องการ

นอกจากฟีเจอร์มาตรฐาน ระบบสามารถต่อยอดและปรับแต่งให้ตรงกับ Workflow ของแต่ละองค์กรได้

BIM INTEGRATION

เชื่อมต่อกับระบบ BIM

เชื่อมโยงเอกสาร RFA/RFI/Shop Drawing เข้ากับโมเดล BIM (เช่น Revit, Navisworks) ผ่าน API เพื่อดูข้อมูลเอกสารประกอบโมเดล 3 มิติได้โดยตรง

FILAMENT ADMIN

อัปเกรดหน้าจอผู้ดูแลระบบด้วย Filament

ปรับปรุง Backend เดิมด้วย Laravel/Filament เพื่อ Dashboard ที่ทันสมัย จัดการข้อมูลรวดเร็วขึ้น และรองรับการขยายฟีเจอร์ในอนาคต

API INTEGRATION

เชื่อมต่อระบบภายนอกผ่าน API

เปิด API สำหรับเชื่อมต่อกับระบบ ERP, ระบบบัญชี, หรือระบบสารบรรณเดิมขององค์กร ลดการทำงานซ้ำซ้อนระหว่างระบบ

WORKFLOW ENGINE

ปรับ Workflow การอนุมัติเฉพาะองค์กร

ออกแบบขั้นตอนการอนุมัติเอกสารหลายระดับ (Multi-level Approval) ให้ตรงกับโครงสร้างสายบังคับบัญชาของแต่ละหน่วยงาน

MOBILE APP

พัฒนาแอปพลิเคชันมือถือเสริม

ต่อยอดเป็นแอปสำหรับหน้างาน ให้ทีมช่างและวิศวกรอนุมัติเอกสารหรือรายงานความคืบหน้าได้จากไซต์งานโดยตรง

REPORT & BI

รายงานเชิงวิเคราะห์และ BI Dashboard

เชื่อมต่อกับเครื่องมือ Business Intelligence เช่น Power BI/Metabase เพื่อวิเคราะห์แนวโน้มโครงการเชิงลึก

ทุกการปรับแต่งออกแบบตามขอบเขตงานจริงของลูกค้า ทีมงานประเมินความเป็นไปได้ทางเทคนิคและระยะเวลาพัฒนาให้ก่อนเริ่มงานทุกครั้ง เพื่อให้มั่นใจว่าการต่อยอดระบบสอดคล้องกับ Workflow เดิมขององค์กรและใช้งานได้จริง
